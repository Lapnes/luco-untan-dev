# Program Magister (S2) Informatika UNTAN

Informasi pembukaan resmi Program Studi Magister (S2) Informatika di lingkungan Fakultas Teknik, Universitas Tanjungpura (UNTAN).

---

## 1. Pembukaan Resmi Program Magister

Universitas Tanjungpura secara resmi menyelenggarakan Program Magister (S2) Informatika menyusul terbitnya izin operasional resmi dari Kementerian Pendidikan Tinggi, Sains, dan Teknologi (Kemdiktisaintek):
- **Status Program**: Resmi Dibuka dan Aktif Menerima Mahasiswa Baru
- **Jenjang Pendidikan**: Strata Dua (S2) Pascasarjana
- **Gelar Lulusan**: Magister Komputer (M.Kom.)
- **Website Resmi**: [Portal S2 Informatika UNTAN](https://s2informatika.untan.ac.id/)

---

## 2. Sorotan Berita & Rekognisi Peluncuran

Pembukaan program magister ini mendapat apresiasi langsung dari pimpinan kementerian dan institusi mitra:
1. **Apresiasi Menteri Diktisaintek**: Peluncuran Program Magister Informatika diapresiasi sebagai penguat pilar talenta komputasi dan kecerdasan buatan terdepan di kawasan Kalimantan Barat dan perbatasan Indonesia-Malaysia.
2. **Sosialisasi Akademik Lintas Kampus**: Pengelola prodi menyelenggarakan roadshow dan sosialisasi program magister ke berbagai perguruan tinggi mitra (antara lain Politeknik Negeri Sambas / Poltesa) untuk menjaring calon mahasiswa dari kalangan akademisi, birokrasi, dan praktisi industri teknologi.

---

## 3. Informasi Admisi & Kontak Pascasarjana

Calon pendaftar program pascasarjana dapat mengakses informasi kurikulum S2, jadwal seleksi penerimaan, serta persyaratan administrasi pendaftaran melalui portal resmi:
- **Website**: `https://s2informatika.untan.ac.id/`
- **Sekretariat**: Gedung Fakultas Teknik Universitas Tanjungpura, Jl. Prof. Dr. H. Hadari Nawawi, Pontianak 78124
- **Surel**: info@informatika.untan.ac.id
