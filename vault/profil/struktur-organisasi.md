## 3. Kelompok Keahlian (KK)

Pengelolaan keilmuan, penelaahan outline tugas akhir (SPOTA), dan pembagian bidang riset dibagi ke dalam 4 Kelompok Keahlian resmi:

| Kelompok Keahlian (KK) | Jumlah Anggota Dosen | Fokus Riset & Pembelajaran |
| :--- | :---: | :--- |
| **Komputasi dan Kecerdasan Buatan** | **9 Dosen** | Machine Learning, NLP, Pemrosesan Citra Digital, Soft Computing, Algoritma Optimasi |
| **Rekayasa Perangkat Lunak dan Komputasi Bergerak** | **8 Dosen** | Software Engineering, Mobile Computing, Web Engineering, UI/UX, Agile Development |
| **Jaringan, Keamanan Siber, dan Internet of Things** | **7 Dosen** | Computer Networks, Network Security, Cyber Forensics, Cloud Computing, Sensor IoT |
| **Sistem Informasi dan Data Spasial** | **9 Dosen** | Enterprise Architecture, Geographic Information Systems (GIS), Business Intelligence, Data Engineering |

*Catatan*: Posisi Ketua pada masing-masing Kelompok Keahlian saat ini berstatus transisi organisasi dan belum ditetapkan secara definitif di portal resmi prodi.
