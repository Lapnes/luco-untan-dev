# Template & Repositori Dokumen Resmi Informatika UNTAN

Katalog lengkap template penulisan, pedoman akademik, formulir administratif, dan sertifikat resmi Program Studi Sarjana Informatika, Fakultas Teknik, Universitas Tanjungpura (UNTAN). Seluruh berkas bersumber dari repositori resmi prodi (`https://informatika.untan.ac.id/dokumen/`) melalui CDN Directus API.

Untuk setiap dokumen resmi, mahasiswa dapat memilih:
1. **Pratinjau / Naskah Markdown (.md)**: Naskah bersih hasil ekstraksi PyMuPDF4LLM & Mammoth untuk dibaca langsung atau disalin teksnya.
2. **Unduh Berkas Asli (Raw PDF / DOCX)**: File biner master asli dengan format dan tata letak asli dari dekanat/jurusan.

---

## 1. Standar Format & Tipografi Penulisan (Pedoman 2022 FT UNTAN)

Setiap dokumen akademik resmi (Proposal Tugas Akhir, Laporan Skripsi, dan Laporan Kerja Praktik) wajib mematuhi parameter tata letak:

| Parameter | Ketentuan Baku Pedoman 2022 | Keterangan Teknis |
| :--- | :--- | :--- |
| **Ukuran Kertas** | **A4** (21,5 × 29,7 cm) | Kertas HVS putih polos minimal 70 gram |
| **Warna Cover Skripsi** | **Biru Muda** | Seperti warna biru benhur |
| **Margin Kiri (*Left*)** | **4 cm** | Mengakomodasi 1 cm untuk ruang penjilidan |
| **Margin Atas (*Top*)** | **3 cm** | Batas tepi atas kertas |
| **Margin Kanan (*Right*)** | **3 cm** | Batas tepi kanan kertas |
| **Margin Bawah (*Bottom*)** | **3 cm** | Batas tepi bawah kertas |
| **Jenis Huruf (*Font*)** | **Times New Roman** | Warna hitam tegas untuk seluruh naskah |
| **Ukuran Font Teks Isi** | **12 pt** | Spasi 1.5 baris (*line spacing 1.5*), rata kanan-kiri (*justify*) |
| **Ukuran Font Judul Bab** | **14 pt**, **Bold**, KAPITAL | Posisi tengah (*center*), diawali penomoran BAB I, BAB II, dst. |
| **Ukuran Font Sub-Bab** | **12 pt**, **Bold**, *Title Case* | Rata kiri, penomoran berjenjang angka Arab (1.1, 1.2, 2.1) |
| **Spasi Khusus** | **1.0 spasi (Tunggal)** | Abstrak, judul tabel/gambar panjang, kutipan langsung, dan daftar rujukan |
| **Lambang UNTAN** | **Segilima** (bukan bundar) | Diameter 4 cm pada halaman cover dan judul |
| **Nomor Halaman** | Angka Arab | Sudut kanan atas; khusus halaman pertama setiap bab diletakkan di tengah bawah |
| **Format Sitasi** | **IEEE Style** | Sistem urutan nomor kemunculan (`[1]`, `[2]`), bukan alfabetis |
| **Kode Program** | Font *monospace* | Courier New / Lucida Console bernomor baris dan berlabel judul ("Kode program X.Y") |
